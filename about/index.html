👤 ABOUT THE WEBMASTER // TIM WASSON 👤

System Profile & Mission

Greetings! I am Tim Wasson (handle: @wasson). This webpage was created to serve as the base root website for https://neogramtest.neocities.org and as a living showcase and test bed for widgets generated by Neogram.

The web was meant to be fun, personal, and decentralized. No algorithmic feeds, no intrusive surveillance trackers — just pure HTML, CSS with Sass, and static hosting on Neocities.
